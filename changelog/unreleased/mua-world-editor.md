The Admin Preview page is now a World editor. Edit the World's EDL beside the preview, then Build a fresh World from it, or Migrate the preview to it while keeping its play state. A Migration shows its plan (atoms, entities created, renamed, updated or gone, and play state kept), then each component it changed, linked to the inspector. What the editor produces is EDL to commit. It never changes the live World.
